# امنلاک (amnlak) — نقشه املاک و محاسبات ساختمان

اپلیکیشن اندروید فارسی و راست‌چین با صفحه اصلی نقشه‌محور، ثبت آزمایشی ملک و ۲۸ ماشین‌حساب ساختمان و معاملات. ماشین‌حساب‌ها آفلاین‌اند و نمایش نقشه به اینترنت نیاز دارد.

| مشخصه | مقدار |
|---|---|
| نام برنامه | امنلاک |
| نام پکیج | `com.amnlak.calculator` |
| نسخه آزمایشی | ۰.۲ (`versionCode = 2`) |
| حداقل اندروید | ۵.۰ (API 21) |
| تارگت | اندروید ۱۴ (API 34) |
| تعداد ابزار | ۲۸ ماشین‌حساب در ۶ گروه |
| توسعه‌دهنده | محمد جواد قهرمانی — ۰۹۱۲۷۲۸۵۰۶۵ |
| وب‌سایت | [amnlak.ir](https://amnlak.ir) |

## قابلیت‌ها

- صفحه اصلی نقشه OpenStreetMap با زوم نزدیک و انتقال خودکار به موقعیت کاربر
- نمایش نقطه و محدوده تقریبی دقت موقعیت کاربر روی نقشه
- دکمه موقعیت روی نقشه برای دریافت دوباره مختصات و تمرکز روی محل کاربر
- صفحه ورود با شعار «املاک تخصص ماست — دیوار که جای ملک نیست»
- مجموعه آیکون‌های خطی مینیمال و یک‌دست در منوها و صفحات داخلی
- لوگوی صفحه ورود با پس‌زمینه شفاف و لبه‌های پاک‌سازی‌شده
- ثبت موقعیت ملک با لمس نقشه و فرم کامل مشخصات
- ورود پیامکی آزمایشی با کد ۱۲۳۴۵
- ذخیره محلی آگهی و آماده‌سازی متن برای تلگرام مدیر
- نوار پایین «نقشه، ثبت ملک، محاسبات، حساب من»
- رابط فارسی و فونت وزیرمتن
- ۲۸ ماشین‌حساب آفلاین ساختمان و املاک
- منوی همبرگری، گروه‌بندی و جستجوی سریع
- حالت شب با ذخیره انتخاب کاربر
- تاریخچه ۵۰ محاسبه آخر با تاریخ شمسی و امکان بازکردن مجدد
- اشتراک‌گذاری نتیجه و فهرست تاریخچه
- اسپلش‌اسکرین، انیمیشن‌ها و تور راهنمای اولین اجرا
- صفحه پشتیبانی و صفحه کامل ارتباط با توسعه‌دهنده
- انتخاب چند تصویر از فایل‌خوان اندروید بدون دسترسی مستقیم به حافظه

## گروه‌های محاسبات

1. **سازه، بتن و آهن:** بتن فونداسیون، سقف، ستون و تیر؛ وزن میلگرد؛ برآورد فولاد ساختمان
2. **دیوار و مصالح:** آجر و بلوک، ملات دیوارچینی، سیمان بتن، ماسه و سیمان ملات، اندود سیمانی
3. **نازک‌کاری:** کاشی و سرامیک، رنگ، سنگ، ایزوگام، گچ و سفیدکاری
4. **متره و عملیات:** خاکبرداری، خاکریزی، قالب‌بندی ستون، مساحت تقریبی زمین
5. **هزینه ساخت:** برآورد کل ساخت، هزینه یک ردیف کار، پیشنهاد قیمت پیمانکار
6. **املاک و معاملات:** کمیسیون خریدوفروش، کمیسیون رهن‌واجاره، تبدیل رهن و اجاره، قیمت هر متر، بازده اجاره

> نتایج برای برآورد اولیه‌اند و جایگزین نقشه مصوب، متره تفصیلی، نظر مهندس، تعرفه رسمی اتحادیه یا مشاوره حقوقی و مالی نیستند.

## ساخت APK

```bash
bash tools/setup-env.sh     # نصب JDK 17 و Android SDK؛ فقط بار اول
APKNAME=amnlak-v0.2-prototype.apk VCODE=2 VNAME=0.2 bash build.sh release
```

برای تغییر نسخه:

```bash
VCODE=2 VNAME=0.2 bash build.sh
```

ساخت نسخه انتشار نیازمند `keystore.properties` و کلید اختصاصی انتشار است:

```bash
bash build.sh release
```

پروژه بدون Gradle و مستقیماً با `aapt2`، `javac`، `d8` و `apksigner` ساخته می‌شود.

## ساختار پروژه

```text
android/src/main/
├── AndroidManifest.xml
├── java/com/amnlak/calculator/MainActivity.java
├── res/                              آیکون و تم اندروید
└── assets/www/
    ├── index.html                    پوسته برنامه
    ├── styles.css / property.css     رابط، نقشه و فرم ثبت ملک
    ├── property.js                  موتور نقشه، ورود و ثبت آزمایشی

    ├── calculators.js               گروه‌ها، فرمول‌ها و ۲۸ ابزار
    ├── app.js                       مسیریابی، تاریخچه، جستجو و صفحات
    ├── img/                          لوگو و تصاویر توسعه‌دهنده
    └── fonts/                        فونت وزیرمتن
```

راهنمای توسعه در [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md) قرار دارد.
